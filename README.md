# Odin Recipes
A simple recipe website built with HTML as part of The Odin Project curriculum.

## Project Overview
This project is a basic multi-page website that displays different recipes.
It was created to practice fundamental HTML concepts and basic Git workflows.

## What I learned
- Basic HTML structure and syntax  
- Working with headings, paragraphs, lists, links, and images  
- Creating multiple pages and linking them together  
- Organizing a small project structure  
- Writing clear Git commit messages  

## Challenges
- Forgetting to add closing HTML tags  
- Minor IDE auto-formatting issues  

## Next steps
- Add basic CSS styling  
- Improve layout and visual appearance  
- Make the website responsive
